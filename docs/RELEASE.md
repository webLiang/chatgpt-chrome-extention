## Versioned download

The current repository version in `extention/manifest.json` is **`1.26.1020.11845`**, synchronized from the Chrome Web Store on 2026-10-27. It has not been published as a new GitHub Release. The latest published release remains [**v1.26.1005.11759**](https://github.com/webLiang/chatgpt-chrome-extention/releases/tag/v1.26.1005.11759), with these assets:

- `chatgpt-chrome-extention-v1.26.1005.11759.zip`: the `extention/` directory at that release tag, ready to extract and load through Chrome Developer mode.
- `SHA256SUMS.txt`: the ZIP's SHA-256 checksum, for checking download integrity.

That published ZIP includes the old version's 38 distribution files. It excludes `.DS_Store`, repository history, documentation, local backups, the archived bridge experiment, and machine state. The source archives generated by GitHub contain the full repository at the release tag and are separate from this installation ZIP.

Extract the ZIP into a permanent location and select its `extention/` directory in Chrome's **Load unpacked** dialog. See the [installation guide](INSTALL.md).

## Packaging from a release tag

The existing release's extension-only ZIP can be reproduced from its tag with Git:

```sh
git archive --format=zip --output=chatgpt-chrome-extention-v1.26.1005.11759.zip v1.26.1005.11759 extention
shasum -a 256 chatgpt-chrome-extention-v1.26.1005.11759.zip > SHA256SUMS.txt
```

Before upload, compare the ZIP file set and extracted file hashes with `maintenance/baseline-1.26.1005.11759.json`. Check its manifest version, public-key-derived ID, and referenced resources. The release tag must point to the exact source commit used to make the asset. Record actual browser verification separately in [VERIFICATION.md](VERIFICATION.md); packaging checks alone do not prove a live browser connection.

For a future release of the current source, use `1.26.1020.11845` in the tag and ZIP name and compare against `maintenance/baseline-1.26.1020.11845.json`, following the [maintainer handoff](MAINTAINER.md). Keep old releases and baselines available.

`extention/` contains third-party vendor code and assets. This project is unofficial; the restored public key and working local connection do not establish endorsement or grant redistribution rights. `UNLICENSED` in `package.json` grants no license through that metadata and does not relicense vendor code under ISC. No npm build or runtime is required.
